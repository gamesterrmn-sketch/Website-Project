VENDOR PERFORMANCE WEBSITE

FILES
- index.html: complete responsive website
- vendor-performance-teaser.mp4: embedded 30-second teaser video

HOW TO PREVIEW
1. Keep both files in the same folder.
2. Double-click index.html.

HOW TO PUBLISH ON NETLIFY DROP
1. Extract the ZIP file.
2. Go to https://app.netlify.com/drop
3. Drag the vendor_performance_website folder onto the page.
4. Wait for deployment.
5. Copy the exact public URL shown by Netlify.

Alternative: upload both files to a GitHub repository and enable GitHub Pages.
